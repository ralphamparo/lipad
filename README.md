# Lipad — cheapest flights from the Philippines to anywhere

Lists the cheapest fares leaving PH airports (MNL, CEB, CRK, DVO, ILO, KLO, PPS, TAG)
to every destination. You can filter by departure airport, one-way or round trip, travel dates (any dates, by month, by week, or a custom departure range with an optional return-by date and quick ranges; the month and week pickers show the cheapest fare for each, from `/api/lows`),
trip length (weekend, short trip, about a week, about 2 weeks or custom nights; round trips only, `nights=6-8`), number of adults (prices and budget cover the whole group), direct flights only, max budget, region and search text. Filters are saved in the URL, so a search can be shared.

## Run

```bash
node apps/ph-cheap-flights/server.js 4325          # sample fares
TP_TOKEN=xxx TP_MARKER=123 node apps/ph-cheap-flights/server.js 4325   # live fares
```

Open http://localhost:4325

## Live prices

1. Sign up free at https://www.travelpayouts.com and join the **Aviasales** program.
2. Copy your **API token** and **partner marker** from the dashboard.
3. Put them in `apps/ph-cheap-flights/.env` (gitignored, never served by the site):
   ```
   TP_TOKEN=...
   TP_MARKER=...
   ```
   or set them as environment variables on the host (these take priority over `.env`).

To find as many fares as possible, the server checks two Travelpayouts sources:
`aviasales/v3/prices_for_dates` (overall, plus one lookup for each of the next 12 months when "Anytime" is chosen) and
`v2/prices/latest`. It keeps these fares in one combined list; every date filter (`/api/deals?from=&to=&returnBy=`) is applied to that list, keeping the cheapest fare per route. Ranges shorter than 14 days also get a lookup for each day. Lookups run 5 at a time and retry if the service
says to slow down. Results are cached for 30 minutes, and the default "all airports, anytime" searches refresh in the
background. "See this fare" links go to Aviasales with your partner marker and the chosen number of adults.
Prices come from recent traveller searches and are not guaranteed.

Other free sources I looked at in September 2026: Amadeus Self-Service shut down on July 17, 2026, and Kiwi Tequila is invite-only.
Skyscanner is partner-only. Ignav has a free allowance, but it only searches one route and date at a time, not "anywhere".

Without a token, the site shows sample fares with a visible notice. Their links open a Google Flights search.

## Installable app (PWA)

`manifest.webmanifest` + `sw.js` make the site installable: on Android, Chrome offers "Install app" (the header
button appears when the browser allows it); on iPhone, Safari → Share → Add to Home Screen. It then opens
full-screen with its own icon. The service worker caches only the app shell (HTML/CSS/JS/icons) — never fares —
and an offline notice shows when the connection drops. Icons were generated by
`scratchpad/make-icons.js` (plain Node, no dependencies) into `icons/`.

## Your own ads (no network needed)

Lipad can serve ads you sell directly — a dive shop, a hostel, a tour operator — with no approval
process and no revenue share. Set `ADMIN_TOKEN` on the server, then open `/admin.html` and sign in
with it to add sponsors, see views, clicks and click rate, pause or delete them.

Each sponsor has a headline, optional body text, button text, link, optional image (max 600 KB,
stored in `uploads/`) and background colour. Targeting: which of the three slots it may fill
(above / between / below results), optional regions (e.g. `East Asia`) and destination codes
(e.g. `HKG, TYO`), a run window, and a weight for how often it shows against other sponsors.

Views are counted when an ad is served; clicks go through `/go/<id>`, which counts and redirects.
Data lives in `data/ads.json` (never served to the web) and creatives in `uploads/`.

Your own ads take priority; AdSense only fills slots you haven't sold.

## Ads

`config.js` holds the settings, and nothing loads until it has an AdSense client id.

1. Deploy to a real domain first — AdSense will not review a localhost site.
2. Apply at https://adsense.google.com, then create two display ad units.
3. Fill in `adsenseClient`, `adsenseSlotTop` and `adsenseSlotBottom`.

The slots sit above and below the results grid, each labelled "Advertisement". Never use AdSense inside a
packaged app's webview — that breaks AdSense policy; a packaged build uses AdMob instead.

## Packaging as an Android/iOS app (later)

The same files wrap with Capacitor: copy this folder into the Capacitor project's `www/`, set `apiBase` in
`config.js` to the deployed server URL (a packaged app has no local server), then add AdMob for in-app ads.
Google Play also wants a privacy policy (`privacy.html`) and the data-safety form, and personal accounts created
after 13 Nov 2023 need 12 testers opted in for 14 days before a public release.

## Deploy

The site needs its Node server because the token has to stay hidden, so plain static hosting won't work. Use Render, Railway or Fly.io:
start command `node server.js`, and set `PORT`, `TP_TOKEN` and `TP_MARKER`.
